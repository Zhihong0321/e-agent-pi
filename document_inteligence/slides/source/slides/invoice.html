数据库结构：tenant → customer / contact，product / package / tax_code，document（报价单、发票、信用票据类型）和 document_line，payment 和 payment_allocation。价格、税额和客户资料在开单时复制到单据上，日后改目录不影响旧单。发出时才分配编号，并冻结内容。“先思考，后动手”指 prepare_document：它不写任何东西，只是解析客户和产品、按开单规则找出缺项、给出建议（如有效期）和价格估算，Document Agent 把所有问题合并在一条消息里问用户。
