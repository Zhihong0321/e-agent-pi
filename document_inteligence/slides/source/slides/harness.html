更好管：Harness 加 Checker

HARNESS

把边界写死

  • 只能通过指定工具工作：没有文件、没有 Shell、没有 SQL
  • 只看得到自己的工具，借不到别人的；主机再校验一次
  • 不持有数据库密码，所有操作由主机代为执行

CHECKER AI

对照输入与结果

  • 开单、收款、作废、发布等不可逆操作，先核对用户是否真的这样要求
  • 回复后核对单号、金额、状态是否与数据库一致
  • 不达标就退回原 Agent 重做，最多 2 次

Harness：agent 运行在 assistant 权限下，没有文件、Shell、SQL，唯一能力是 MCP 工具，且每个 agent 只看到自己的工具；主机会再校验一次，每个 agent 的令牌不能冒充别的 agent。Checker：一个独立的模型（与工作模型不同家族），只在不可逆写入前和回复后介入；不达标退回原 agent，最多重试 2 次，之后带着“Checker 未能确认”的提示发出。判断出错时放行，不阻塞工作。诚实说明：目前 Checker 在评测环境中运行并验证，尚未接入线上聊天。
