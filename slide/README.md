## 使用

双击 `index.html` 即可离线打开。图片已内嵌，不需要安装依赖或连接网络。

- 左右方向键 / Page Up / Page Down：翻页
- Home / End：第一页 / 最后一页
- N：显示或隐藏当前页讲稿
- F：切换全屏（也可使用浏览器 F11）
- 打印 / PDF：输出全部 15 页；附带的 PDF 已导出
- 地址末尾 `#4`：直接打开第 4 页

## 编辑

修改 `deck.html` 后在仓库根目录执行 `node slide/build.mjs`，生成自包含 `index.html`。两张 PNG 为来源素材。`check.mjs` 使用仓库已有的 Playwright，检查版式与交互、保存各页截图并导出 PDF。
